# English Assistant Migration Matrix (`116510b`)

Audit baseline: commit `116510b`. The matrix distinguishes the active plugin tree at that commit from existing Dart analysis in Flutter Core. Python remains available temporarily for differential checks; the final plugin is required to contain no Python runtime or `.py` source/build/test files.

> Product decision on 2026-10-29: OCR is out of scope. OCR rows below describe historical sources/dispositions only; no OCR implementation, assets, transport or engine selection is planned.

## Plugin Engine and API

| Source | Current behavior/use | Destination/disposition | Evidence to retain |
|---|---|---|---|
| `engine/service.py` | At audit baseline, FastAPI exposed sentence-role, DGNL and OCR routes. | Removed after disabling the Python sidecar; Phase 04 will add the Dart text-only API. | Regression confirms the manifest has no Python backend; API cutover remains a Phase 04 task. |
| `engine/dgnl_analyzer.py` | DGNL metrics/highlights and Cloze generation, may use spaCy when available. | Port supported DGNL profile/highlight behavior into plugin Dart; remove all Cloze generation. | `engine/benchmarks/ocr_benchmark.py` | Historical runner called the removed sentence-role endpoint. | Deleted as a stale endpoint client; no replacement OCR benchmark is planned. | Historical OCR reports remain in the repository for provenance only. |
