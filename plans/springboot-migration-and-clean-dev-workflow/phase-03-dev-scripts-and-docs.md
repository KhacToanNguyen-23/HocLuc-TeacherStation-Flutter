# Phase 3: Tạo công cụ chạy 2 CMD & Cập nhật README

## Requirements
- Create `dev-backend.bat` in root: launches `mvn spring-boot:run` in `backend/service`.
- Create `dev-frontend.bat` in root: auto-detects `flutter` in PATH, or falls back to `.sdk/flutter/bin/flutter.bat`, and runs `flutter run -d chrome`.
- Update `README.md` to clearly document the new 2-CMD workflow and updated structure.
