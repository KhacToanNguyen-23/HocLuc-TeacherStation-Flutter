# Học Lực Teacher Station

Dự án xây dựng nền tảng giảng dạy trực tuyến dành cho Giáo viên (Teacher Station).
Nền tảng mục tiêu: **Desktop (Windows/macOS)**.
Công nghệ cốt lõi: **Flutter / Dart**.

## Cấu trúc nhóm tính năng (Giai đoạn 1)
- **Scenes (Quản lý layout):** Teacher, Board, Question, Solution.
- **Teaching Canvas (Bảng trắng):** Hiển thị công thức, vẽ tay (handwriting).
- **Students (Tương tác):** Chat, Giơ tay, Trắc nghiệm nhanh (Polls).
- **Toolbar:** Quản lý Mic/Cam, Lọc tiếng ồn (Noise Cancellation), Bấm giờ.

## Bắt đầu với dự án
Hiện tại dự án đã được khởi tạo Git. Để thêm thành viên, bạn cần đưa repository này lên GitHub hoặc GitLab.

1. File prototype giao diện (UI) hiện đang nằm tại: `lib/main.dart`.
2. Nếu team chưa cài Flutter, có thể copy code trong file này dán lên [DartPad](https://dartpad.dev/) để xem thử.
3. Nếu đã cài Flutter, chạy lệnh `flutter create .` tại thư mục này để gen ra các file hệ thống, sau đó `flutter run`.
